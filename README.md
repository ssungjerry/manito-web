# 🎁 시크릿 마니또 (Secret Manito) - 비밀 친구 & 미션 뽑기

팀원들이 각자의 링크로 접속하여 **본인만 마니또 대상과 비밀 미션을 확인**할 수 있는 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **1인 1링크 비공개 매칭**:
   - 주최자가 참가자 명단(줄바꿈/쉼표)을 입력하면, 각 팀원에게 전달할 **고유 비밀 링크**(`.../#/reveal?t=...`)가 일괄 생성됩니다.
   - 각 링크에는 해당 참가자의 매칭 정보만 암호화되어 담겨 있어, 다른 사람의 링크를 알 수 없고 완벽한 비밀이 유지됩니다.

2. **완전 순열(Derangement) 보장**:
   - 수학적으로 본인이 본인을 뽑는 일이 절대 일어나지 않습니다.
   - 단일 순환(Hamiltonian Cycle) 방식을 적용하여 3인 이상일 때 둘만의 맞교환(A↔B) 없이 하나의 큰 원으로 공정하게 매칭됩니다.

3. **풍부한 마니또 미션 라이브러리**:
   - 칭찬 & 응원, 간식 & 서프라이즈, 배려 & 서포트, 센스 & 위트 등 센스 있는 프리셋 미션 20여 종 제공
   - 주최자가 직접 커스텀 미션을 추가하거나 제외할 수 있습니다.

4. **원클릭 단체방 공유 포맷**:
   - **[슬랙 / 카카오톡 맞춤 일괄 복사]** 버튼 한 번으로 팀 단체 채팅방에 바로 공지할 수 있는 예쁜 텍스트 템플릿이 클립보드에 복사됩니다.
   - 팀원별 전송 완료 체크박스 및 개별 링크 복사 지원

5. **두 가지 인터랙티브 개봉 모드**:
   - 🎁 **선물상자 열기 (3D Unbox)**: 상자를 터치하면 뚜껑이 열리며 화려한 폭죽(Confetti)과 팡파레 효과음 재생
   - 🪙 **스크래치 복권 (Scratch)**: 골드 홀로그램 복권을 마우스나 손가락으로 직접 긁어 확인하는 재미

6. **사생활 보호 & 이미지 저장**:
   - 🙈 **사생활 보호 (다시 가리기)**: 동료가 지나갈 때 누르면 즉시 전체 화면 블러 처리
   - 📸 **결과 카드 이미지 저장**: 본인 기기 갤러리에 간직할 수 있는 고해상도 지령서 PNG 다운로드

7. **실시간 클라우드 DB 연동 (Firebase Firestore)**:
   - ☁️ **전 기기 실시간 비밀번호 잠금 동기화**: 단체방 링크에서 한 팀원이 본인 비밀번호를 등록하면, 다른 모든 팀원의 화면에서 즉시 `🔒 비밀번호 잠김` 상태로 변경되어 타인의 열람을 완벽 차단합니다.
   - 📊 **실시간 확인 현황 대시보드**: 주최자는 대시보드에서 누가 마니또를 확인했는지 실시간 프로그레스 바로 모니터링할 수 있습니다.
   - ⚙️ **브라우저 1초 연동 UI**: 우측 상단 `[☁️ 클라우드 DB]` 버튼을 통해 코드 수정 없이도 Firebase 설정을 붙여넣고 바로 활성화할 수 있습니다. (미설정 시 안전한 로컬 모드로 자동 동작)

## 🚀 로컬 실행 방법

```bash
# 의존성 설치 (최초 1회)
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드 (dist 폴더 생성)
npm run build
```

브라우저에서 `http://localhost:5173/`으로 접속하시면 바로 이용하실 수 있습니다.

## 🌐 무료 웹 배포 방법 (GitHub Pages / Vercel / Netlify)

본 애플리케이션은 별도의 데이터베이스나 백엔드 서버 없이 동작하는 클라이언트 기반 웹 앱이므로 어디서든 정적 호스팅이 가능합니다:

1. **Vercel**: GitHub 저장소 연결 후 클릭 한 번으로 배포 (`npm run build`, 출력 디렉터리: `dist`)
2. **GitHub Pages**: `dist` 폴더 내용을 `gh-pages` 브랜치에 푸시
3. **Netlify**: `dist` 폴더를 드래그 앤 드롭하여 10초 만에 배포
